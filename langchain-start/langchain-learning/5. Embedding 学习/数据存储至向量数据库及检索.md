# Retriever 检索

## ​Retriever的核心作用​​
### 1. ​​语义匹配而非关键词匹配​​
- Retriever 利用​​嵌入模型​​（Embedding Model）将用户查询和文档转换为高维向量（如768维或1024维），通过计算向量间的​​余弦相似度​​或​​欧氏距离​​，实现基于语义的相似性搜索。
- 与传统关键词检索（如Elasticsearch）不同，它能理解同义词、上下文关联和抽象概念（例如“环保”与“可持续发展”的语义关联）。
### ​2. ​在RAG框架中的关键地位​​
- 在检索增强生成（RAG）系统中，Retriever 负责从向量数据库中召回与用户问题相关的文档片段（Context），再交给大语言模型（LLM）生成最终回答。
- 例如：用户问“气候变化的影响”，Retriever 会召回与“温室效应”“海平面上升”等语义相关的文档块。
### 3. ​​支持多种检索策略​​
- **​相似度搜索​​（Similarity Search）**：返回与查询向量最相似的Top K个结果。
- **​最大边际相关性​​（MMR）**：平衡相关性与多样性，避免结果重复（例如在推荐系统中）。
- ​**​阈值过滤​​（Score Threshold）**：仅返回相似度分数超过设定值的结果（如 score_threshold=0.8）。
